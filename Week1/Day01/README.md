# Day 01 - Two Sum

| Problem | Approach | Time | Space |
|---|---|---|---|
| Two Sum | Brute force - check every pair | O(n²) | O(1) |
| Two Sum Less Than K | Check every pair and keep best sum < K | O(n²) | O(1) |
| 3Sum | Brute force - check every triplet | O(n³) | O(1) |
| Two Sum II | Brute force - check every pair | O(n²) | O(1) |
| Pair with Given Sum | Brute force - check every pair | O(n²) | O(1) |

## Extra Points
- Pair problems use 2 loops.
- 3Sum uses 3 loops.
- Brute force is simple but slower for large inputs.
