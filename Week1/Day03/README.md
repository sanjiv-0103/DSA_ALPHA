# Day 03 - Single Number

| Problem | Approach | Time | Space |
|---|---|---|---|
| Single Number | XOR all elements | O(n) | O(1) |
| Missing Number | Compare expected sum and actual sum | O(n) | O(1) |
| Find the Difference | XOR character values | O(n) | O(1) |
| Single Element in Sorted Array | XOR all elements | O(n) | O(1) |
| Single Number II | Frequency counting using dictionary | O(n) | O(n) |

## Key Points
- `a ^ a = 0`
- `a ^ 0 = a`
- XOR works when duplicate values appear in pairs.
- Single Number II needs a different approach because values appear three times.
