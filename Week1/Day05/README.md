# Day 05 - Majority Element

| Problem | Approach | Time | Space |
|---|---|---|---|
| Majority Element | HashMap frequency counting | O(n) | O(n) |
| Majority Element (GFG) | HashMap frequency counting | O(n) | O(n) |
| Check If a Number Is Majority Element in a Sorted Array | Count target occurrences | O(n) | O(1) |
| Element Appearing More Than 25% in Sorted Array | HashMap frequency counting | O(n) | O(n) |

## Key Points :
- HashMap helps count how many times each number appears
- Majority element appears more than n/2 times
- For 25% majority, the count should be more than n/4
- Frequency counting is simple and easy to understand
- HashMap approach was used for the primary problem
