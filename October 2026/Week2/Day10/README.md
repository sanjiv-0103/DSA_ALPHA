# Day 10 - Two Pointer Practice

| Problem | Approach | Time | Space |
|---|---|---|---|
| Remove Duplicates from Sorted Array | Read pointer checks values, write pointer stores unique values | O(n) | O(1) |
| Remove Element | Read pointer skips target value, write pointer stores remaining values | O(n) | O(1) |
| Move Zeroes | Read pointer stores non-zero values first, then fill remaining positions with zero | O(n) | O(1) |

## Key Points
- Two pointers move in the same direction.
- `read` checks every element.
- `write` stores the required values.
- All three problems are solved in-place with O(1) extra space.
