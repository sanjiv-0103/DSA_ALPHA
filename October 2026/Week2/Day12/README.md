# Day 12 - Squares of a Sorted Array

| Problem | Approach | Time | Space |
|---|---|---|---|
| Squares of Sorted Array | Brute force - square all values and manually sort | O(n²) | O(n) |
| Squares of Sorted Array | Optimized - two pointers from both ends | O(n) | O(n) |
| Sort Array By Parity II | Brute force - place even and odd values into correct positions | O(n) | O(n) |

## Key Points
- Brute force squares all values first and then sorts them
- Optimized approach compares values from both ends
- The larger square is placed from the back of the result
- Parity places even values at even indexes and odd values at odd indexes
