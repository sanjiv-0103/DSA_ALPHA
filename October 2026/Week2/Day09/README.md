# Day 09 - Reverse String

| Problem | Approach | Time | Space |
|---|---|---|---|
| Reverse String | Two-pointer in-place swap | O(n) | O(1) |
| Reverse Vowels of a String | Two pointers-find vowels and swap | O(n) | O(n) |


## Concepts Practised

- Two-pointer technique
- Moving pointers from both ends
- Checking and reversing only vowels
