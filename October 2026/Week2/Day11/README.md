# Day 11 - Merge Sorted Array

| Problem | Approach | Time | Space |
|---|---|---|---|
| Merge Sorted Array | Brute force - combine values and manually sort | O((m+n)²) | O(1) |
| Merge Intervals | Brute force - compare and merge overlapping intervals | O(n²) | O(n) |

## Key Points
- Brute force checks and arranges values directly.
- Merging from the back avoids overwriting values.
- Merge Intervals combines overlapping ranges.
