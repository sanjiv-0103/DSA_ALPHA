# Day 14 - Contains Duplicate II

| Problem | Approach | Time | Space |
|---|---|---|---|
| Contains Duplicate II | Brute force - check every pair and index distance | O(n²) | O(1) |
| Permutation in String | Brute force - check every window and compare character counts | O(n*k) | O(k) |

## Key Points
- Contains Duplicate checks whether equal values are within distance `k`
- Brute force compares pairs directly
- Permutation in String checks each window of the same size as the first string
- Char frequencies are compared to identify a permutation
